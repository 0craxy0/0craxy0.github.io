Introducing Lucid

Running a script should be the easy part. You shouldn’t have to trade performance for compatibility, lose your setup when you change games, or guess what went wrong.

Lucid brings it all into one Windows workspace. A complete, optimized script environment, an editor with useful diagnostics, and a home for every game, script and client. Built to work together from the start.
